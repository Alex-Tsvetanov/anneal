# Vendored TSPLIB instance

`berlin52.tsp` is the published TSPLIB instance *berlin52* (52 locations in
Berlin). Coordinates and the EUC_2D weight type are taken from TSPLIB; they are
not generated by this project.

- Source library: Gerhard Reinelt, *TSPLIB — A Traveling Salesman Problem
  Library*, ORSA Journal on Computing, 3(4):376–384, 1991.
  DOI: [10.1287/ijoc.3.4.376](https://doi.org/10.1287/ijoc.3.4.376)
- Published optimum under the TSPLIB EUC_2D (`nint`) convention: **7542**
- `berlin52.opt.tour` is the corresponding published tour (1-based city indices),
  used only to verify that evaluating that tour yields 7542 under the same
  distance convention.

TSPLIB instances are distributed for academic use with the library. This tree
keeps a single small EUC_2D file so measurements against a known optimum need
no network access. `att48` was not chosen: its weight type is ATT
(pseudo-Euclidean), which this reader does not implement and which is not
comparable under plain Euclidean length.
